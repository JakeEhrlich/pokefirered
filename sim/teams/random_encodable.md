# random_encodable

2500 teams of uniformly random mons that fit in `struct Pokemon` but usually break FireRed's legality
rules (illegal moves, key items / TMs as held items, second ability on a species that has none, ...).
Expected verdicts: `encodable` (a few `ok` by luck), never `invalid`.

Generated by `sim/tools/gen_encodable_teams.py`; ids `re_1` .. `re_2500`, source `random_encodable`,
tags `["random", "encodable"]`.

## Regenerate

```
python3 sim/tools/gen_encodable_teams.py --count 2500 --seed 1        # writes sim/teams/random_encodable.jsonl
python3 sim/tools/teams.py check sim/teams/random_encodable.jsonl --quiet
```

Result with seed 1: `2500 teams: 10 ok, 2490 encodable, 0 invalid`.

## Sampling rules

Every field is drawn independently with a seeded `random.Random(seed)`; name tables come from
`teams.py names` (the checker's own tables), so the generator only emits names the checker resolves.

| field | distribution |
|---|---|
| team size | uniform 1..6 |
| format | `doubles` with p = 0.1 when the team has >= 2 mons, else `singles` |
| species | uniform over the 410 species names the checker accepts: ids 1..411 **except 252** (`OLD_UNOWN_B`, dropped from the checker's name table). `OLD_UNOWN_C`..`OLD_UNOWN_Z` (253..276) and `UNOWN` (201) are included; the `UNOWN_B`.. letter forms (412+) are not encodable and are not in the table. `NONE` and `EGG` are excluded |
| level | uniform 1..100 |
| moves | count k uniform 1..4, then k distinct moves uniform over the 353 move names the checker accepts: ids 1..354 **except 68** (`COUNTER`, dropped from the checker's name table because `teams.py` excludes every define whose name contains `_COUNT`) |
| item | uniform over all 375 item names, ids 0..374: `NONE`, balls, medicine, key items, mail, TMs/HMs, and the unnamed slots (`034`, `0E2`, `10B`, ...). All are encodable; only holdable ones are `ok` |
| ability | slot number, uniform over {0, 1} (slot 1 on a species with a single ability is `encodable`, not `ok`) |
| nature | uniform over the 25 natures |
| ivs | 6 x uniform 0..31 (game stat order HP/Atk/Def/Spe/SpA/SpD) |
| evs | 6 x uniform 0..255, then **if the total exceeds 510 every stat is rescaled as `ev_i = floor(ev_i * 510 / total)`**; totals <= 510 are left as sampled. Since the mean raw total is 765, almost every mon is rescaled and lands at a total of 505..510 (mean 501 including the rare unscaled ones). Each stat stays in 0..255 and the total never exceeds 510 |
| happiness | uniform 0..255 |
| ot | `player` with p = 0.9, `outsider` with p = 0.1 |
| fateful | true with p = 0.5 |
| nickname | always null |

Accepted ranges (what `build/teamcheck` calls encodable): species 1..411, level 1..100, moves 1..354,
item 0..374, nature 0..24, IV 0..31, EV 0..255 with total <= 510, ability slot 0/1. The checker
accepted every sampled value; the only narrowing is the two names missing from its name table
(species 252, move 68).
